1. WHAT THIS PROJECT IS
================================================================================

Angad is an Indian markets (NSE) AI trading analysis terminal. You watch;
the system predicts and explains. The UI is designed like a modern trading
desk (Zerodha Kite–style candlestick chart) rather than a simple plot.

Core capabilities:
  - Live OHLCV candlestick charts with zoom, pan, crosshair
  - Rule-engine + optional Gen AI (OpenAI) predictions
  - Explainable BUY / SELL / HOLD with beginner-friendly reasons
  - Technical indicators (EMA, SMA, VWAP, RSI, MACD, Bollinger, ATR, ADX,
    Volume, Support/Resistance, Fibonacci retracement & extension)
  - Future prediction curve with confidence bands
  - Prediction vs reality comparison (Correct / Incorrect)
  - Full prediction history with accuracy and P/L simulation

Educational prototype — not financial advice.

3. END-TO-END WORKFLOW (EVERY REFRESH ~60 SECONDS)
================================================================================

Step 1 — Load settings
  - config/loader.py merges defaults.json + local.json
  - Optional OPENAI_API_KEY from env or local.json

Step 2 — Market session (IST)
  - market_calendar.py → XNSE calendar: pre_open, open, post_close, holiday

Step 3 — Fetch OHLCV
  - services/market_service.py → providers/market_yfinance.py (Yahoo)
  - Cached briefly depending on interval

Step 4 — Indicators
  - indicators/calculator.py applies technicals + Fibonacci + S/R + patterns

Step 5 — Rule reference signal
  - prediction/rule_engine.py weighted score → BUY / SELL / HOLD + confidence %
  - Used as context for Gen AI (AI may disagree)

Step 6 — News (optional)
  - market_intel / news_service RSS headlines for Gen AI citations

Step 7 — Gen AI brain (if enabled + API key)
  - prediction/genai_engine.py calls OpenAI JSON API
  - Returns: signal, confidence, target, stop, prediction path, reasons

Step 8 — Persist history
  - prediction/history_store.py saves run + projection points to JSON
  - Backfills actual_price / win / P/L for older predictions

Step 9 — UI (Trading Desk)
  - Candlestick chart with overlays
  - AI explanation panel
  - Compare prediction vs reality
  - History + accuracy tabs

5. HOW AI PREDICTION WORKS
================================================================================

5.1 Rule engine (always runs)
  File: prediction/rule_engine.py

  Weighted factors on the latest bar:
    - EMA stack (9/20/50)
    - RSI bands
    - MACD vs signal
    - VWAP distance
    - Volume vs VOL_MA20
    - Bollinger proximity
    - ADX trend strength
    - Fibonacci proximity (61.8% / 50% / 38.2%)

  Thresholds (approx):
    - score strong positive  → BUY
    - score strong negative  → SELL
    - else                   → HOLD

  Confidence is dynamic (not fixed):
    - HOLD: ~42–70% based on neutrality
    - BUY/SELL: ~48–94% based on score strength

  ATR-based stop and target:
    - BUY:  stop = close - k*ATR, target = close + m*ATR
    - SELL: inverted
    - HOLD: symmetric band

5.2 Gen AI engine (optional)
  File: prediction/genai_engine.py

  LLM receives indicator summary, rule reference, market session context,
  and optional news. It returns JSON:
    signal, confidence, target_price, stop_loss, reasons, prediction_path

  If Gen AI fails or is disabled, the rule result is primary.

5.3 Projection path
  File: intraday_forecast.py

  Builds an IST session grid (typically 5m) from the last live candle toward
  the target price. The chart forces the future line to start exactly at the
  last candle close and extend only into future timestamps.

5.4 Confidence score
  - Rule: derived from score magnitude + RSI neutrality checks
  - Gen AI: model-reported confidence, clamped to a sensible range
  - Chart confidence bands widen when confidence is lower

8. PREDICTION VS REALITY
================================================================================

For every evaluated prediction the UI shows:

  Prediction:        BUY @ Price X
  Actual Result:     Price moved to Y
  Difference:        +2.4%
  Prediction Status: Correct / Incorrect

Evaluation rules (history_store.update_actual_prices):
  - Predictions older than ~5 minutes get actual_price = latest close
  - BUY wins if actual >= predicted * 0.99
  - SELL wins if actual <= predicted * 1.01
  - HOLD wins if error_pct <= 1.0
  - profit_loss_pct simulates directional P/L
  - Chart annotations plot the same comparison on candles

9. FIBONACCI ALGORITHM
================================================================================

File: indicators/fibonacci.py

  1. Find swing high / swing low over lookback (default 50 bars)
  2. Classify trend from close vs midpoint of the swing
  3. Retracements at 0%, 23.6%, 38.2%, 50%, 61.8%, 78.6%, 100%
  4. Extensions at 127.2%, 161.8%, 200%
  5. Nearest support / resistance derived from retracement levels
  6. fibonacci_signal_contribution() adds score when price is near key levels

15. KNOWN LIMITATIONS
================================================================================

  - Yahoo Finance delay / gaps can affect intraday candles
  - Gen AI quality depends on API key, model, and prompt context
  - Prediction paths are illustrative session projections, not guaranteed prices
  - P/L simulation is a simplified educational metric (± directional)
  - Plotly is used instead of native TradingView Lightweight Charts
    (look/feel is Kite-inspired; not a pixel clone of Kite)
  - No broker order placement — analysis only
