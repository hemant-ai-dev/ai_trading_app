
---

## Database

The app uses a local SQLite file:

`data/storage/trading_tool.db`

Tables are created automatically on first start. Data is kept across restarts.

Optional path override: environment variable `ANGAD_SQLITE_PATH`.

To wipe the database during development only (never automatic):

```bash
python scripts/reset_sqlite_db.py --yes-delete-all-data --confirm DELETE
```

**Hosting:** Streamlit Community Cloud and many PaaS disks are ephemeral. SQLite files there can disappear on redeploy/restart unless you attach persistent storage (volume, disk, or an external database). Do not assume cloud SQLite is permanent.

The first signed-up account becomes **Admin**. Admins open **User Management** in the sidebar.
